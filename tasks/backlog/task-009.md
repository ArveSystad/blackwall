## Goal
One place to configure everything.

## Scope

- Agent library editor.
- Tags: editable list, seeded (see grill-result.md §5).
- Defaults: agent per role, concurrency cap per repo (default 3).

## Acceptance criteria
- Every setting persists and is used by new tasks.
