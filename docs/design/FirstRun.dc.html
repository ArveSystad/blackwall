First run

Agents work inside. Nothing crosses the wall without you.

Two things before the first task: somewhere to read work from, and a repo to work in.

  1. 1
    Add a connection GitHub.com, a GitHub Enterprise host, or Jira Cloud. Tokens stay on this machine.
  2. 2
    Register a repository Point at a local clone, or scan a folder like ~/code and pick from what's found.
  3. 3
    Start a task From a Jira key, a PR URL, or a plain prompt.
